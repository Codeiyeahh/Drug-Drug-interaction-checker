A deep-learning-powered web application designed to predict the likelihood of interactions between two drugs based on their pharmacological and pharmacokinetic parameters.

---

## 🌟 Overview

The **Drug-Drug Interaction Checker** uses a Feedforward Neural Network (FNN) trained on curated pharmacological datasets to analyze the potential risk when two drugs are administered simultaneously. By evaluating key parameters like enzyme inhibition, binding affinity, and lipophilicity, the tool provides a probability-based assessment of interaction risk.

## 🚀 Features

- **Deep Learning Core**: Built with PyTorch, utilizing a multi-layer perceptron for high-accuracy predictions.
- **Rich User Interface**: Modern, responsive design with dynamic glassmorphism aesthetics and micro-animations.
- **Pharmacological Parameters**: Analyzes interactions based on:
  - **CYP3A4 Enzyme Type**: Substrate, Inhibitor, or Inducer.
  - **Binding Affinity**: Molecular attraction strength (nM).
  - **Renal Clearance**: Rate of drug elimination via kidneys (mL/min/kg).
  - **LogP**: Partition coefficient (lipophilicity).
- **Interactive Samples**: Pre-loaded datasheets for common drugs (e.g., Ketoconazole, Simvastatin, Ritonavir) for quick testing.
- **Real-time Visualization**: Dynamic probability bars and clear safety indicators.
- **Persistent History**: Keeps track of your recent searches using local storage.

## 📦 Installation

### Prerequisites
- Python 3.8 or higher
- Pip (Python package manager)

### Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Codeiyeahh/Drug-Drug-interaction-checker.git
   cd Drug-Drug-interaction-checker
   ```

2. **Create a virtual environment (optional but recommended)**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install flask flask-cors numpy torch
   ```

4. **Run the application**:
   ```bash
   python app.py
   ```

5. **Access the tool**:
   Open your browser and navigate to `http://127.0.0.1:5000`.

## 🧬 Model Information

The underlying model is a Feedforward Neural Network with the following architecture:
- **Input Layer**: 14 features (Pharmacokinetic data + One-hot encoded CYP3A4 types).
- **Hidden Layers**: Two fully connected layers (64 and 32 neurons) with ReLU activation and Dropout (0.3) for regularization.
- **Output Layer**: Sigmoid activation for binary classification (Interaction vs. No Interaction).

The model was trained using the `drug_interaction_model_best.pth` weights, achieving robust performance on imbalanced pharmacological datasets.
