🧠 About the Model

The prediction engine uses a Feedforward Neural Network (FNN) trained on a one-hot-encoded pharmacological dataset. It takes 14 input features — CYP3A4 enzyme classification (4-class one-hot) and three continuous parameters per drug — and outputs an interaction probability via a sigmoid-activated output layer. The model was trained using PyTorch and is served via a Flask REST API.
